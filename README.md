## Selected projects

### Spatial Transcriptomics to Proteomics Prediction
Built LightGBM, graph-based and spatial-neighbour modelling experiments for predicting 44 protein-expression maps from RNA, spatial coordinates and pathology data. Improved local Top-10 mean Spearman performance from 0.468 to 0.629 and supported a cross-patient submission scoring 0.5585 on an unseen patient.

### Interpretable Deep Learning for Healthcare Time Series
Designed a clinically aligned evaluation framework comparing interpretable and deep-learning models for ICU time-series prediction, with emphasis on calibration, faithfulness, stability and temporal localisation.

### Natural-Language Image Generation
Developed a multi-stage neural pipeline for text-conditioned image generation using attention and transfer-learning experiments with BLIP and SigLIP.
